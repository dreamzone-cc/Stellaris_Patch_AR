# 🌟 Stellaris Patch AR v1.0

## Arabic Translation Tool for Stellaris

### 📁 What's Included

This is a standalone executable that contains:
- ✅ **Complete Arabic Translation Files** (embedded)
- ✅ **Arabic Fonts** (embedded)  
- ✅ **Background Music** (embedded)
- ✅ **Custom Icon** (embedded)
- ✅ **All Required Libraries** (embedded)

### 🚀 Quick Start

1. **Download** `Stellaris_Patch_AR.exe`
2. **Place it anywhere** on your computer
3. **Double-click** to run
4. **Follow the simple steps** in the application

### 📂 File Structure After Running

```
📁 Your chosen location/
├── 📄 Stellaris_Patch_AR.exe    (The main application)
└── 📁 Backup Data/               (Created automatically)
    └── 📁 Your backups...        (Safe backup storage)
```

### 🎮 How to Use

1. **Run** `Stellaris_Patch_AR.exe`
2. **Select** your Stellaris game folder
3. **Create Backup** (recommended)
4. **Apply Arabic Patch**
5. **Launch Stellaris** and select **Korean language** in Paradox Launcher
6. **Enjoy** Stellaris in Arabic! 🎉

### ⚠️ IMPORTANT

**You MUST select Korean language in Paradox Launcher for the Arabic patch to work!**

The game will think it's displaying Korean text, but you'll see Arabic translations instead.
